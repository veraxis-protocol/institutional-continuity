# Evaluations

This directory contains **published, pinned evaluations**, not marketing comparisons.

## Current board

No vendor/system is currently scored in the bootstrap.

A future evaluation should identify:

- exact system/version;
- exact ICI/ICTS/profile versions;
- exact evidence references;
- exact vector/criteria identities where relevant;
- environment/toolchain;
- evidence class;
- known limitations;
- result digest;
- reviewer/reproduction status.

Veraxis receives no privileged treatment.

A partial-system evaluation may establish specific joins without claiming full ICI.
