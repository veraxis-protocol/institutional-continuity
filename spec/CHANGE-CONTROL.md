# Normative Change Control

A material normative change requires a successor artifact.

## Triggering changes

Examples include:

- canonical-chain changes;
- join eligibility changes;
- status-semantics changes;
- new or relaxed bounded-satisfaction rules;
- profile interpretation changes;
- invariant changes;
- error/refusal behavior changes;
- evidence-class changes;
- digest/canonicalization changes that alter identity;
- benchmark pass-condition changes.

## Required change record

Every material change record must state:

1. predecessor identity;
2. successor identity;
3. rationale;
4. exact semantic change;
5. compatibility impact;
6. benchmark impact;
7. formal-obligation impact;
8. migration impact;
9. claim-ceiling impact;
10. owner/design-authority approval.

## History

Do not edit old frozen evidence in place to make it match the new rule.

A correction is evidence about the predecessor, not permission to erase it.
