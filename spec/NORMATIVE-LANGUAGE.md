# Normative Language

When a released specification explicitly declares this convention, the key words:

**MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, NOT RECOMMENDED, MAY, OPTIONAL**

are to be interpreted as described in **BCP 14**, consisting of RFC 2119 and RFC 8174, when and only when they appear in all capitals as shown here.

- RFC 2119: https://www.rfc-editor.org/rfc/rfc2119
- RFC 8174: https://www.rfc-editor.org/rfc/rfc8174

Because this repository is PRE-1.0, a document must still identify whether it is normative; capitalization alone does not promote explanatory text into a normative requirement.
