# Normative Language

When a released specification explicitly declares this convention, the key words:

**MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, MAY, OPTIONAL**

are to be interpreted as normative requirement levels in the conventional standards sense.

Because this repository is PRE-1.0, a document must still identify whether it is normative; capitalization alone does not promote explanatory text into a normative requirement.
