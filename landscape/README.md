# Institutional Continuity Landscape

The landscape maps technologies to ICI joins and infrastructure roles.

It is not a leaderboard.

Candidate categories include:

- identity and delegation;
- policy/rules-as-code;
- institutional admission/semantic conservation;
- capability and authorization protocols;
- execution-integrity systems;
- outcome/consequence attestation;
- supply-chain provenance;
- independent observation;
- reconciliation/completeness systems;
- audit/replay/examination systems.

A landscape entry must distinguish direct evidence from analyst inference and must identify the version/source used for the mapping.
