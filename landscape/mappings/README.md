# Landscape Mappings

Each mapping should contain:

- system/protocol;
- exact version/date;
- primary sources;
- ICI joins addressed;
- joins explicitly not established;
- evidence class;
- uncertainties;
- last review date.

Do not call a technology a “competitor” merely because it occupies one ICI join.
