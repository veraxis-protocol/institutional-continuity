# Support

This repository is primarily technical infrastructure and specification work.

Use GitHub issues for:

- specification clarification;
- interoperability questions;
- benchmark methodology;
- implementation mappings;
- documentation defects.

Do not use public issues for undisclosed security vulnerabilities; see `SECURITY.md`.

Commercial implementation, managed-service, licensing, or formal rights inquiries should use the contact channels published at `veraxis.io`.
