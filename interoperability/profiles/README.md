# ICI Compatibility Profiles

Compatibility Profiles let independent implementations say precisely which ICI joins they claim and under what bounds.

A useful public statement looks like:

> “System X establishes J3–J5 under profile P, with no claim for J1–J2 or J6–J8.”

That is preferable to an undefined “ICI compatible” badge.

Profiles must not redefine full ICI by deleting required joins.

Third-party profiles are welcome and do not imply endorsement.
