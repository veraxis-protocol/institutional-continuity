# Interoperability

The interoperability layer defines how independent systems can participate in ICI without adopting Veraxis internals.

Open interoperability surfaces may include:

- object identity;
- handoff contracts;
- compatibility profiles;
- verifier behavior;
- failure/refusal semantics;
- evidence references;
- conformance vectors;
- release/version identities.

Open interfaces do not require publication of proprietary methods used to derive or operate those objects.
