# Evidence Record

ICI applies its own historical-continuity requirements to its development record.

## Principles

- preserve failed measured runs;
- preserve superseded normative artifacts;
- issue corrections as successors;
- identify evidence class;
- separate author-directed review from independent reproduction;
- never upgrade an evidence class through wording alone.

## Public evidence

Only evidence approved for public disclosure belongs in this repository.

Private working evidence may exist elsewhere without becoming canonical merely because it predates the public record.
